📲 Cara Pasang di Android & Desktop

  1. Di Desktop (Chrome/Edge): Klik ikon Install di address bar atau tombol Install Aplikasi di sidebar.
  2. Di Android (Chrome): Buka link yang sama (atau tempel Link Pairing), ketuk menu ⋮ → Tambahkan ke layar utama / Install app.
  3. Akses Beda Jaringan: Deploy folder proyek ini ke layanan cloud gratis (Render / Railway / Netlify / VPS) lalu masukkan URL-nya di kolom Server Cloud di atas.
